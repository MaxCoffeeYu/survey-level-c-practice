# 測量丙級術科練習

技術士技能檢定測量丙級術科（試題編號 04200-970301）的線上練習網站，依「(1100701 起報檢者適用) 丙級測量技術士術科」應檢參考資料製作，答案紙照原格式呈現。

測驗內容（45 分鐘，含觀測與計算）：

1. 經緯儀水平角測量：P 點整置，單角法正倒鏡觀測 ∠APB 一測回
2. 水準儀直接水準測量：C→TP1→D 往測、D→TP2→C 返測，求 D 點平均高程（HC = 30.000m）
3. 捲尺直接距離測量：E、F 量三次取平均

為方便練習，三部分可分開練習（各自只評相關的評審項目，另換算百分制），也可選「完整試題」模擬 45 分鐘、100 分的完整檢定。

## 練習模式

1. **術科外業＋內業練習**：第一人稱操作經緯儀（HR／V 顯示、0SET、正倒鏡）、水準儀（5mm 式水準尺自行判讀，自行選位置放置尺墊）、2mm 鋼捲尺；結束外業後完成計算交卷，與場地真值比對評分。
2. **純內業練習**：系統隨機生成觀測數據，只做計算，依官方時間計時。
3. **教學引導模式**：使用官方範例數據，依計算順序一格一格說明公式與代入數值。

交卷後依官方評審表評分，並可點選欄位查看計算方式。

本網站為教學練習用途，評分結果僅供參考，實際檢定以監評人員評分為準。
